# Claude Code basic setup (Windows)

One prompt that walks you from the Claude desktop app to a working Claude Code setup: install, bypass permissions, Claude in Chrome, and Google connectors. It is written as an end goal plus a suggested path, so if your laptop, menus, or commands differ (Mac, Linux, a newer version), Claude finds the equivalent and gets you there anyway.

## How to use it

1. Open the Claude desktop app on your laptop.
2. Copy everything in [PROMPT.md](PROMPT.md) (open it, click the copy icon at the top right of the file).
3. Paste it into a new chat and follow what it says. It installs Claude Code, then tells you to paste the same prompt again inside Claude Code.
4. Stuck at any point: say "stuck" and paste a screenshot.

Takes about 20 minutes. Needs a Claude account (Pro or Max is best). Written for Windows, works on Mac and Linux too.

## What you end up with

- Claude Code running in PowerShell with bypass permissions on, so it does not ask before every command.
- Claude in Chrome, so it can open and read web pages for you.
- Google Calendar, Drive and Gmail connected.

Not included on purpose: a rules file, notes vault, automations. Add those once you have used it on a real problem for a week.
